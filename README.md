# RARI FRIENDS — $RARI

Одностраничник под мем-коллекцию **Rari Friends**: 1024 пиксельных френда, у каждого свой кошелёк и один голос.

Идея — скрещивание Rare Friends (NFT-питомцы с собственными кошельками, которые сами копят крипту) и Rarible / RARI (первый governance-токен в NFT: держишь — голосуешь). Итог: **ты покупаешь френда, френд получает кошелёк и голос, и дальше решает сам.**

## Что внутри

- Чистый статический HTML/CSS/JS, без сборки. Один `index.html` + `assets/`.
- **Все 12 персонажей рисуются кодом.** Присланный арт разобран в пиксельные сетки (`GRIDS` в скрипте), персонажи рендерятся на canvas — резкие на любом размере, перекрашиваются, анимируются. Растровых копий персонажей на сайте нет.
- **Глаза следят за курсором** — дырки-глаза сдвигаются на пиксель в сторону мыши, внутри силуэта. Плюс случайные моргания.
- Клик по герою — дождь пиксельных монет + звук, каждый пятый тык меняет френда.
- **THE REGISTRY** — 12 карточек, клик открывает «дело» френда: кошелёк, холдинги, история голосований, реплика от первого лица. Открыл все 12 — дождь монет на весь экран.
- **THE FLOOR** — лента предложений комитета с полосами FOR/AGAINST, которые заполняются при скролле, и комментарием того френда, который за это отвечает.
- Бегущая строка, нижняя лента марширующих френдов (случайный подсвечивается жёлтым).
- Музыка: «committee loop» — арпеджио в 5/4 на square + пульс баса, Web Audio, без файлов. Звук молотка — шумовой импульс через lowpass.
- Кнопки Sound / Music, музыка стартует на первом взаимодействии.

## Настройки

В начале `<body>`:

```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку — пока пусто, кнопка BUY неактивна
```

## Проверено

- `pageerror` пустой на всех вьюпортах.
- Горизонтального скролла нет: 1440×1000, 1352×631, 1280×720, 1024×768, 834×1112, 390×844, 360×740.
- Кнопки CTA видны на первом экране на всех десктопных вьюпортах.
- Персонажи нигде не обрезаны (уши, антенна, ноги) — сверено с исходным листом.
